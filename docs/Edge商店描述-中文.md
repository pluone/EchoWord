# EchoWord —— 让英文网页上的每个陌生单词，都能读出来、看得懂

## 给谁用

备考四六级、考研、雅思托福的学生党——常读外刊与真题；程序员、科研人员、分析师——读文档、逛 Stack Overflow、arXiv；跨境电商与海外运营——盯 Reddit、亚马逊评论；以及把读英文当爱好的兴趣读者——刷 BBC、Medium。他们的共同点：眼睛会看，嘴不会读，读过的也记不住。

## 理念

陌生单词，不读出来就永远学不会。耳朵听过的发音、在句子里用过的单词，才会真正记住。

## 推荐配置

在设置里打开「朗读单词」和「朗读整句」，并勾选「先读单词，再读整句」。阅读时遇到生词，悬停即可：卡片弹出音标、释义与整句中文翻译，先朗读单词，再朗读整句，你顺势在句子里看懂它的用法。

## 主要功能

- 悬停即查：鼠标移到生词上弹出卡片，移开自动消失，不打断阅读；
- 标准发音：清晰自然的语音朗读单词和整句，可选美式或英式音标；
- 在句中学词：不只看释义，更能听到、读懂完整的句子；
- 想用的网站才用：只在英文网页上工作，中文网页不受影响；
- 可固定卡片：想仔细研究时把卡片固定住，看完再关。

陌生单词，不读出来就永远学不会。让 EchoWord 把你读到的每一句英文，都变成学会一个词的机会。
